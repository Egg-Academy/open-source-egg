# Open Source Egg

Egg Academy's mission is to connect the world through creativity.

Open Source Egg is a public place for community tools that serve that mission: practical things people can copy and adapt. The repo is overseen by the Egg Academy. The tools are not all ours. People the Egg Academy has added on GitHub can propose a tool that belongs here.

Each tool lives in its own folder. Nothing here is guaranteed to work in your setup.

**Repository:** [github.com/Egg-Academy/open-source-egg](https://github.com/Egg-Academy/open-source-egg)

Maintainers review pull requests before anything merges to `main`.

Login, email, and file storage stay in **your** own app. This repo holds shared design, reference material, and code you can adapt.

| `nz-police-vetting/` | Design for an NZ Police Vetting Service check (workflow, forms, portal steps). **Your** legal and privacy obligations apply when you implement it. |

## Before you use or change anything

Read [GOVERNANCE.md](./GOVERNANCE.md), [CONTRIBUTING.md](./CONTRIBUTING.md), and [SECURITY.md](./SECURITY.md).

**Never** commit vetting outcomes, identity documents, real people's contact details, passwords, API keys, or live credentials.

The NZ Police consent form in `nz-police-vetting/form/` is Police's blank form. Egg Academy does not own that form.
