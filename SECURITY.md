# Security

## Reporting a vulnerability or serious concern

Email **kane@eggacademy.co.nz**. Do not open a public issue for an exploitable security bug, or for personal data that has been committed.

## Sensitive data in the repo

If you find vetting records, ID documents, or similar in the history:

1. Do not spread the files, or download more than you need to report them.
2. Email **kane@eggacademy.co.nz**. Do not open a public issue.
3. The Egg Academy removes that content from the repository. If a password, token, or key was exposed, it must be changed.

## Scope

This policy covers the **open-source-egg** repository, including tools other people contribute. Your deployed copy of any tool is your responsibility. Test it before you rely on it.
