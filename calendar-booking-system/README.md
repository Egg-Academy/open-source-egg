# Calendar Booking System

A community design for a calendar where guests book a time, for you to build in your own app. Your privacy duties for the contact details you collect stay with you.

Start with [Calendar-Booking-System.md](Calendar-Booking-System.md). It is written so a coding assistant can implement the flow against whatever login, email, and staff list you already have.

| Path | What it is |
| --- | --- |
| `Calendar-Booking-System.md` | The full design: services, times, the public page, the private booking page, admin setup, and emails |

There is no runnable app in this folder. Login, the staff directory, and sending mail stay in your app. See [SHIPPING.md](../SHIPPING.md).
