# Governance

**Open Source Egg** is a community repo looked after by **Egg Academy**.

## What this repo is

- A place for tools from Egg Academy and from other contributors, when they fit the same mission: practical help people can adapt (youth work, admin, booking, compliance workflows, and similar).
- Documentation and reference you can copy. **Not** a hosted service. Egg Academy does not run your copy. You deploy and operate tools in your own systems.

## What this repo is not

- A place for sensitive personal data, vetting results, ID scans, or secrets.
- A guarantee that any tool is complete, lawful for your context, or production-ready.
- Legal advice. Implementers remain responsible for the Privacy Act, vetting rules, employment law, and their own policies.

## Decisions

- **Egg Academy** owns the programme direction and can change structure, licenses, or visibility.
- **Maintainers** (people delegated by Egg Academy) review and merge pull requests to `main`.
- **Everyone** may read, clone, and fork. Only people Egg Academy has added on GitHub can open a pull request. Only maintainers merge to `main`.
- **Contributors** use pull requests after they have write access. That access is granted manually. Joining the website interest list does not add it.

## Visibility and licence

The repo is **public**. Egg Academy decides how each folder is licenced. Significant licence changes should be discussed in an issue before merge.
