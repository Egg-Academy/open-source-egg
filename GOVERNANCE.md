# Governance

**Open Source Egg** is maintained by **Egg Academy** (the organisation).

## What this repo is

- Documentation and reference implementations for tools that help people solve human problems (youth work, admin, booking, compliance workflows, and similar).
- **Not** a hosted service. Egg Academy does not run your copy. You deploy and operate tools in your own systems.

## What this repo is not

- A place for sensitive personal data, vetting results, ID scans, or secrets.
- A guarantee that any tool is complete, lawful for your context, or production-ready.
- Legal advice. Implementers remain responsible for the Privacy Act, vetting rules, employment law, and their own policies.

## Decisions

- **Egg Academy** owns the programme direction and can change structure, licenses, or visibility.
- **Maintainers** (people delegated by Egg Academy) review and merge pull requests to `main`.
- **Everyone** may read, clone, and fork. Only maintainers merge to `main`.
- **Contributors** use pull requests. GitHub collaborator access is granted manually when needed; joining the website interest list is not the same as repo write access.

## Visibility and licence

The repo is **public**. Egg Academy decides how each folder is licensed. Significant licence changes should be discussed in an issue before merge.
